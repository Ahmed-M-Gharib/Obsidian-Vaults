## Overview
Welcome to my DevOps Second Brain. 

I believe that true mastery comes not just from doing labs, but from thoroughly documenting, organizing, and revisiting what you've learned. This Obsidian Vault serves as my personal wiki—a centralized repository where I document everything from fundamental Linux administration to advanced Kubernetes orchestration and AWS infrastructure design.

I'm making this vault public as part of my commitment to learning in public. Whether you are a fellow student, a junior DevOps engineer, or just curious about infrastructure, you are welcome to explore these notes.

## Vault Structure

Currently, the vault is organized into the following core domains:

### Linux
* Administration Basics: User management, permissions, process handling.
* Networking & Security: TCP/IP, DNS troubleshooting, Bastion hosts.
* Shell Scripting: Bash automation and system maintenance scripts.

### Kubernetes (K8s)
* Architecture Notes: Control plane vs. worker nodes.
* Workloads & Networking: Pods, Deployments, Services, and Ingress configurations.
* Storage: Persistent Volumes (PV) and Persistent Volume Claims (PVC).

### Docker
* Foundations: Containers vs VMs, lifecycle management.
* Images: Building optimized images, Dockerfile instructions.
* Advanced: Networking, Volumes, and Docker Compose.

### AWS
* Core Services: EC2, VPC, S3, RDS.
* Architecture: High availability, Auto Scaling, Load Balancing.

*(Note: More domains like Terraform and GitHub Actions are continuously being added as I refine my notes.)*
